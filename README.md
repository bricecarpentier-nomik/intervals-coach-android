# Intervals Coach — versions Android

Ce dépôt ne contient que les fichiers APK de l'application personnelle Intervals Coach
(lecture de données Intervals.icu). Le code source n'est pas publié ici.

## Mises à jour automatiques avec Obtainium

1. Installer [Obtainium](https://github.com/ImranR98/Obtainium).
2. Ajouter une application avec l'adresse de ce dépôt :
   `https://github.com/bricecarpentier-nomik/intervals-coach-android`
3. Obtainium installe chaque nouvelle version publiée dans *Releases*.

L'application ne contient aucune clé ni donnée personnelle : la clé API Intervals.icu
se saisit dans l'application et reste sur le téléphone.
